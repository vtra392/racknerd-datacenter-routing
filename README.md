## 先把线路定性搞清楚

RackNerd 的线路属于普通国际线路。这句话是理解后面所有延迟数据的钥匙。

它没有走中国电信的 CN2 GIA 回程，也不是搬瓦工、DMIT 那类专门采购精品网资源的商家。DC-02 接的是中国电信 163 线路优化加联通 AS4837，晚高峰丢包率比一般美西机房低一些，但“低一些”和“精品网”是两个量级。

搬瓦工 CN2 GIA、DMIT 这类商家更适合对国内响应要求极高的场景，比如面向国内用户的直播、实时语音、在线业务，代价是价格贵出好几倍。一组第三方测试里，某厂商的圣何塞 CN2 线路电信回程延迟 170–182 ms、联通 167–175 ms，和 RackNerd 普通线路的延迟数字差距其实只有二三十毫秒。真正拉开差距的是晚高峰的丢包率和抖动，不是 ping 值本身。看懂这一点，你就不会拿 $18.29/年 的机器去要求 CN2 的稳定性。

## 机房逐个说

### 洛杉矶 DC-02：亚洲优化做得最足，但 1GB 进不去

DC-02 在 Multacom 机房，是 RackNerd 专门做了 Asia Optimized 的节点，电信、联通、网通都接了进来，去程回程基本直连，不绕欧洲或日本。官方的促销公告里反复把它标成“最受欢迎、请求量最大”的机房。

延迟的第三方口径不完全一致：有测评说稳定在 150–180 ms 算正常，电信联通更低；也有汇总给出国内平均 190–200 ms；还有一份搜索摘要落在 170–200 ms。三组数据的测试时点和节点不同，可以认为大致区间在 **150–200 ms**，电信联通偏低、移动偏高。

限制在这里：**DC-02 只对 2GB 内存及以上套餐开放**。官方新年促销公告的原话是“available for PIDs 904 to 907”，也就是 2GB 起的四档。你买 1GB 那款，机房里压根不会出现 DC-02 这个选项，只能选 DC-03、圣何塞、西雅图。想用 DC-02，起步价就是 $18.29/年。

路由上，电信去程普通直连，回程部分走 CN2（AS4134）；联通用 AS4837。白天 SSH 和网页都算跟手，晚高峰电信丢包会明显起来。

### 圣何塞：1GB 唯一能选的西海岸低延迟机房

圣何塞同样是西海岸，三网往返直连，电信去程直连圣何塞，联通走 AS4837，整体延迟多数测评给在 160–180 ms，联通表现尤其稳。库存相对充足，**1GB 小机器也能选**，这是 $11.29/年 想要西海岸时几乎唯一的选项。

移动这一项数据打架比较厉害。多份综合评测说圣何塞移动中转节点偏多，延迟比电信联通高一截，部分节点还绕路；但 2024 年 11 月的一组实测里，移动回程走洛杉矶转香港 CMI 回国，延迟 158–165 ms 反而是三网里最低的，电信那组倒测出 205–259 ms。时点不同、落地节点不同，结论就会反过来。纯移动宽带用户别照抄任何一张表，用测试 IP 自己 ping 一遍最靠谱。

### 西雅图：联通用户的备选

西雅图在西海岸偏北，对联通相对友好，整体延迟比圣何塞略高一点，综合测评给在 190 ms 左右，但比东海岸好太多。DC-02 没货、圣何塞也不满意的时候，它是合理的第三选择。

### 洛杉矶 DC-03：要原生 IP 就看它

DC-03 和 DC-02 不是同一个物理机房，在洛杉矶市中心的另一处设施，出口接 Cogent 等运营商。它的卖点不在速度：**提供美国原生 IP、开放 25 端口**，适合要发邮件、要注册某些对 IP 归属敏感的服务。三网往返基本直连，但优化程度不如 DC-02。

从路由看，电信去程直连美西节点后接 twelve99 进机房，回程走 Cogent 出海、绕圣何塞或圣克拉拉回国，全程纯国际线路，没有 CN2 也没有 AS4134 直连，晚高峰体感一般。把它当“原生 IP 工具机”而不是“低延迟建站机”，预期就对了。

### 达拉斯、东海岸与欧洲

达拉斯在美中，延迟约 217 ms，三网往返直连，联通走 AS4837，移动往返直连、稳定性反而不错，是移动宽带用户可以认真考虑的一个点。

纽约和新泽西在 220–240 ms，比西海岸整体高 60–100 ms，晚高峰容易绕路丢包。它们的价值在流媒体解锁，2024 年 11 月的一组测试给出的 IP 质量排序是纽约优于圣何塞优于洛杉矶，但这组数据已经过去一年多，流媒体政策变得快，只能当参考。

芝加哥约 240 ms，去程还有绕路；阿姆斯特丹、都柏林 270 ms 以上，国内用户基本不用看。

## 三网怎么选

**联通是三网里体验最好的。** 南方联通优先圣何塞，北方联通考虑洛杉矶，两份独立测评给出的结论一致。联通走 AS4837，中途绕路少，晚高峰也比电信扛得住。

**电信白天够用，晚高峰是短板。** DC-02 的电信回程部分走 CN2，白天稳定，晚 8 点后丢包明显上升，部分节点速度掉得厉害。你要是电信宽带、主要白天用，DC-02 可以；晚高峰重度依赖，普通线路确实不够，得去看精品网商家。

**移动最参差。** DC-02 的移动表现还可以，新泽西对移动也算友好，圣何塞的中转节点偏多，达拉斯反而因为往返直连而稳定。移动用户没有一刀切答案，按机房单独测。
